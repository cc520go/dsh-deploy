DSH 一键部署 · 下载

Debian 12：VLESS + Reality 主线，可选 Hysteria2 附加协议。

一条命令安装

curl -fsSL http://64.205.110.102/lisa-install.sh -o /tmp/lisa-install.sh \
  && sha256sum /tmp/lisa-install.sh \
  && bash /tmp/lisa-install.sh --auto --with-hy2

先对比 SHA256SUMS 里的值再执行；校验不通过就不要跑。

文件

  • lisa-install.sh —— 当前版本的单文件安装器（自校验）
  • lisa-install-26.10.21.sh —— 固定版本
  • lisa-26.10.21.tar.gz —— 完整源码包
  • smoke-remote.sh —— 装完的自检清单
  • SHA256SUMS

装完以后

bash smoke-remote.sh          # 一条命令给出 PASS/FAIL 结论
DSH                           # 打开菜单（旧命令 lisa 仍可用）
