本页是测试机上的可选加速镜像，可能随测试机重置而离线；正式渠道见 GitHub Release。

一条命令安装

curl -fsSL http://64.205.110.102/dsh-install.sh -o /tmp/dsh-install.sh \
  && sha256sum /tmp/dsh-install.sh \
  && bash /tmp/dsh-install.sh --auto --with-hy2

先验签再看内容（推荐）

curl -fsSLO http://64.205.110.102/{SHA256SUMS,SHA256SUMS.asc,dsh-signing-key.asc}
gpg --import dsh-signing-key.asc          # 一次性
gpg --verify SHA256SUMS.asc SHA256SUMS    # 必须是 Good signature
sha256sum -c SHA256SUMS --ignore-missing  # 必须是 OK

任一失败就不要执行安装器。公钥指纹：8E25C6FC8FA01719137FAAE6BC9AF5236E467872

文件

  • dsh-install.sh —— 当前版本的单文件安装器（自校验）
  • dsh-install-1.2.0.sh —— 固定版本
  • dsh-1.2.0.tar.gz —— 完整源码包
  • smoke-remote.sh —— 装完的自检清单
  • SHA256SUMS · SHA256SUMS.asc（签名）
  • dsh-signing-key.asc（公钥）

装完以后

bash smoke-remote.sh          # 一条命令给出 PASS/FAIL 结论
DSH                           # 打开菜单
