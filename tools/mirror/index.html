DSH 一键部署 · 下载

Debian 12：VLESS + Reality 主线，可选 Hysteria2 附加协议。

一条命令安装

curl -fsSL http://64.205.110.102/lisa-install.sh -o /tmp/lisa-install.sh \
  && sha256sum /tmp/lisa-install.sh \
  && bash /tmp/lisa-install.sh --auto --with-hy2

先验签再看内容（推荐）

curl -fsSLO http://64.205.110.102/{SHA256SUMS,SHA256SUMS.asc,dsh-signing-key.asc}
gpg --import dsh-signing-key.asc          # 一次性
gpg --verify SHA256SUMS.asc SHA256SUMS    # 必须是 Good signature
sha256sum -c SHA256SUMS --ignore-missing  # 必须是 OK

任一失败就不要执行安装器。公钥指纹：63AEB2BD09A2458B54D7AB1E7F938C08CA8E68D6

文件

  • lisa-install.sh —— 当前版本的单文件安装器（自校验）
  • lisa-install-26.10.31.sh —— 固定版本
  • lisa-26.10.31.tar.gz —— 完整源码包
  • smoke-remote.sh —— 装完的自检清单
  • SHA256SUMS · SHA256SUMS.asc（签名）
  • dsh-signing-key.asc（公钥）

装完以后

bash smoke-remote.sh          # 一条命令给出 PASS/FAIL 结论
DSH                           # 打开菜单（旧命令 lisa 仍可用）
